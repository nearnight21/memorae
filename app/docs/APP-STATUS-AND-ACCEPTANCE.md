# Mobile App 功能状态与验收

最后更新：2026-08-23

这份文档回答三个问题：App 已经能做什么、哪些只是代码已经写好、下一步怎样判断真的完成。

## 状态怎么读

- **代码已实现**：源码中已经有这项功能，但不代表真实设备上已经通过。
- **自动检查通过**：类型检查、协议测试或构建检查通过。
- **真机已验证**：在 Android 真机上实际操作过，并观察到预期结果。
- **待验收**：还不能对外声称完成，需要按本文步骤操作并记录结果。

## 当前开发优先级

1. **P0：补齐 Memory 生命周期和安全闭环**。完成 Create → Read → Edit → Delete，并覆盖编辑字段、照片增删、删除 tombstone 跨设备同步和 COS 密文照片清理策略；同时接入 Home 锁定入口。
2. **P1：搞清真实数据差异**。解释远端、本机和地图可见数量的差异，记录每条未显示记录的原因，并处理历史冲突。
3. **P2：补齐照片和性能验收**。覆盖 5/15/30 MB、前后台、长时间地图操作、分阶段加载和资源释放。
4. **P3：低优先级能力**。导出/导入加密 JSON 和 Android Keystore/指纹解锁作为备份与便利功能，不阻塞主流程。

## 当前唯一验收目标

下一步先关闭下面这一条，不继续增加新功能。创建、查看、编辑和删除代码已经完成，当前剩余重点是真机和跨设备验收：

```text
真实账号登录
→ 创建或打开私密空间
→ 创建一条带地点和照片的记忆
→ 修改标题、正文、日期、地点和照片
→ 删除 Memory，生成 tombstone 并同步到另一设备
→ 验证删除后的地图、详情和本地照片清理；记录 COS 孤儿密文 GC 缺口
→ 接入 Home 锁定入口并验证敏感数据清理
```

在“记录差异、地图选点、详情页、锁定入口”关闭前，不能称为主流程完成，也不应把同步、备份或指纹解锁当作主流程完成标志。

## 21 条中只有 17 条可见，先看哪一类问题

首页不是把服务器返回的每条记录直接画出来。当前代码会经过四道筛选：

1. **服务器冲突**：同一记忆在本机和服务器使用同一版本号但内容不同。现在会跳过这条冲突，继续保存其他远端记忆，并在状态中报告冲突数量；不会自动覆盖任一侧。
2. **解密失败**：坏密文会被跳过，其他记录继续显示。
3. **没有有效坐标**：没有地点，或 `lat/lng` 不是有效数字的记忆不会进入地图 Marker。
4. **年份筛选**：选择某一年后，其他年份会暂时从地图中隐藏。

因此“21 条、17 条可见”目前不能直接判断是哪一种。登录后状态诊断中的以下数字才是证据：

```text
远端同步数量
本机解密数量 / 解密失败数量
地点数量 / 有效坐标数量
地图 DTO 数量
```

其中地图 DTO 数量就是实际发送给地图的数量。若要定位具体 4 条，还需要记录它们的记忆 ID、解密错误类型、是否有地点和坐标；当前 UI 只显示汇总数量，尚未显示逐条原因。

本次 Redmi 真机复核记录：远端 26 条，已落盘 21 条，成功解密 17 条，解密失败 0 条，冲突 5 条；本机解密 20 条，地图有效坐标 19 条，地图运行时显示 19 个地点。照片缓存在 20 秒窗口内未完成，首页现在会明确显示“已同步 21 条远端记忆，有 5 条冲突未覆盖。照片缓存同步超时”，不再把它写成“远端记忆未同步”。

## 通过标准

本轮只有同时满足以下条件，才把主流程标记为“完成”：

- `npm run verify` 通过。
- 表中所有非阻断项通过，没有“暂时可以”或人工猜测。
- 21 条记录的差异已能逐条解释，不能只写“有 4 条冲突”。
- 详情页真实显示标题、正文、地点和照片状态。
- 已有 Memory 可以修改标题、正文、日期、地点并增删照片，保存后版本号正确递增（代码已覆盖，真机待验收）。
- 删除 Memory 会生成可同步的 tombstone；另一设备下载后不再显示该 Memory，且不会被旧版本重新复活（自动测试已覆盖，真机待验收）。
- 本地无引用照片会清理；COS 当前没有物理删除/GC API，远端无主密文必须单独补 GC 能力后才能宣称彻底清理。
- Home 有明确可操作的锁定入口，并且锁定后敏感内容确实消失。
- 锁定后不能通过返回、切换年份或点击地图重新看到敏感内容。
- 错误密码不能进入首页。
- 新建的记忆重新锁定、解锁后仍然存在且地点不漂移。
- 记录 APK 的构建提交号和设备信息；不记录账号密码、私密空间密码或照片明文。

## 失败后怎么处理

- 第 1 项失败：先处理 Android 构建或原生启动问题，不测业务功能。
- 第 2-3 项失败：只检查账号、空间解锁和本地密钥流程，不改地图。
- 第 5-6 项失败：只检查坐标、Marker 和详情回传，不改同步协议。
- 第 7-9 项失败：优先处理内存清理和会话生命周期，这是安全阻断。
- 第 10 项失败：检查新建记忆保存和刷新，不扩大到照片或长时性能。
