# 所忆 App UX Blueprint

> 版本：v0.1（交给 Figma 前的交互骨架）
>
> 日期：2026-08-17
>
> 目标设备：iPhone 393 x 852（Canonical），Android 仅做系统边界与安全区适配验证

## 这份文档解决什么

这不是视觉稿，也不是组件清单。它先确定移动端地图、记忆阅读、时间浏览和新增记忆如何连成一个连续体验，避免把 Web 页面缩小后交给 Figma。

本版本只冻结以下产品判断：

- 地图是持续存在的主场景。打开记忆、阅读记忆和添加记忆都发生在地图上下文中，不用“地图页 -> 详情页 -> 返回地图”的页面跳转表达核心流程。
- App 的一级目标只有“沿地图回看”和“快速添加记忆”。暂不设计“首页 / 足迹 / 相册 / 我的”四栏导航。
- 时间轴继承 Web 的水晶设计语言，但移动端静止时薄、操作时放大；它只负责时间范围，不承担保存记忆字段。
- 地区是地图视野的空间结果；精确跳转和主题筛选通过按需打开的 Bottom Sheet 完成。
- 记忆详情是地图上的连续展开状态，不是普通 Bottom Sheet。Bottom Sheet 只承载地区、筛选、日期、照片候选和快速操作等短任务。

## 核心使用路径

### 沿地图回看

```text
打开 App
  -> 地图默认态
  -> 点击照片或地点
  -> 记忆选中态（地图仍可见）
  -> 上滑记忆卡
  -> 记忆阅读态（地图仍可见）
  -> 下滑、关闭或点击地图
  -> 回到默认态
```

### 添加一条记忆

```text
地图默认态
  -> 点击添加
  -> 选择照片 / 拍照 / 手动添加
  -> 系统读取时间、GPS 和照片信息
  -> 确认或修改地点与时间
  -> 渐进式填写内容
  -> 保存
  -> 新标记在原地图位置出现
  -> 继续添加，或在原地查看这条记忆
```

任何一步取消，都回到原地图视野；不重置已有时间、主题筛选或地图中心点。

## 地图上的层

地图容器在整个流程中保持挂载。界面按层组织，后出现的层不能把地图替换成新的页面：

```text
Layer 0  系统边界：状态栏安全区、Home Indicator 安全区、键盘
Layer 1  地图场景：瓦片、照片标记、聚合标记、相机视野
Layer 2  常驻轻控件：地区跳转、筛选入口、添加入口、必要的定位反馈
Layer 3  时间轴：静止薄条；拖动时临时放大
Layer 4  记忆展开层：选中卡片与完整阅读卡片，始终露出地图
Layer 5  任务浮层：地区 / 筛选 / 日期 / 照片候选等单一 Bottom Sheet
```

同一时刻最多出现一个任务浮层。记忆阅读层和任务浮层不能嵌套；打开地区或筛选时，记忆卡先收回到地图默认态。

### 手势优先级

| 场景 | 垂直拖动 | 水平拖动 / 点击 | 地图双指操作 |
| --- | --- | --- | --- |
| 默认态 | 地图平移 | 点击标记或控件 | 地图缩放 |
| 选中态 | 在记忆卡上拖动展开；卡片外仍可操作地图 | 点击照片切换或关闭 | 在露出的地图区域缩放 |
| 阅读态 | 记忆正文滚动；从卡片顶端下滑收回 | 控件按其命中区域响应 | 仅在露出的地图区域响应 |
| 时间轴操作 | 时间轴区域由时间轴独占 | 拖动手柄预览日期 | 地图不响应该次触摸 |
| 任务浮层 | Bottom Sheet 按吸附点移动 | 选项点击 | 地图只作为背景，不接收单指拖动 |

## 六个 Canonical 状态

每个状态都要在 Figma 中以“用户做什么 -> 界面发生什么”的注释交付，而不是只交一张静态页面。

### 1. 地图默认态

```text
+-----------------------------------+
|  中国 · 山西 · 太原          [筛选] |
|                                   |
|              MAP                  |
|        o       o       [ + ]       |
|                                   |
|                                   |
|                                   |
|              [薄时间轴]            |
|          safe area / home         |
+-----------------------------------+
```

用户打开 App 后直接看到地图、照片标记和薄时间轴。地区控件只显示当前地图视野的层级结果；添加入口是地图上的明确动作，不设置底部一级导航。

用户做什么 -> 界面发生什么：

- 点击照片或地点 -> 相机做轻微聚焦，目标标记变为选中态，记忆卡从地图下方原地展开；不发生路由切换。
- 拖动或缩放地图 -> 地图更新；视野稳定后更新地区摘要，时间和主题筛选不被重置。
- 点击时间轴 -> 时间轴展开到可操作高度，并显示当前范围；点击空白处不应误触发地图标记。
- 点击地区或筛选 -> 只打开对应任务 Bottom Sheet。
- 点击添加 -> 进入新增流程，地图继续作为背景上下文。

### 2. 点击一张记忆：选中态

```text
+-----------------------------------+
|  中国 · 山西 · 太原                |
|              MAP (轻度压暗)        |
|                  [目标照片放大]     |
|                                   |
|          +------------------+      |
|          |       PHOTO      |      |
|          | 太原 · 2024.10   |      |
|          | 那天我们……       |      |
|          |        ^ 上滑     |      |
|          +------------------+      |
|              [薄时间轴]            |
+-----------------------------------+
```

记忆卡是可拖动的地图覆盖层，默认只显示照片、地点、日期和一小段摘要。地图仍要保留足够的可辨识区域，让用户知道自己没有离开原场景。

用户做什么 -> 界面发生什么：

- 上滑卡片 -> 进入阅读态，卡片扩大，正文开始出现。
- 点击目标照片 -> 在原地切换照片，不跳到相册页；其他标记降低存在感。
- 点击关闭、地图空白处或系统返回 -> 卡片收回，回到默认态并保留地图视野。
- 在卡片外拖动地图 -> 允许平移；卡片内的垂直拖动优先由卡片处理。

### 3. 展开完整记忆：阅读态

```text
+-----------------------------------+
|        仍可见的地图带               |
|  [返回地图]       [更多]             |
|-----------------------------------|
|          PHOTO / PHOTO STRIP       |
|  太原 · 鄞州区       2024.10.12     |
|                                   |
|  那天我们沿着旧路走了很久……         |
|  ...                               |
|                                   |
|             下滑收回                |
+-----------------------------------+
```

阅读态不是全屏详情页：顶部或边缘始终保留地图带，地图相机位置不丢失。长正文在阅读层内部滚动，正文不会被 Bottom Sheet 的吸附逻辑截断。

用户做什么 -> 界面发生什么：

- 上下滚动正文 -> 只滚动内容；照片、地点和日期保持上下文。
- 下滑阅读层顶部 -> 连续回到选中态，再次下滑才收回默认态。
- 点击地点信息 -> 关闭阅读层并平滑聚焦地图，不打开第二个详情页。
- 点击编辑 / 删除 -> 进入对应单一任务流程；完成或取消后回到当前记忆的选中态。

### 4. 拖动时间轴

静止时不抢地图空间；开始操作后才增加高度和信息密度：

```text
静止：       2023      2024      2025
              .         *         .
        ------o------------------------

操作中：              2024
                       |
                 +-----------+
        ---------o-----------
                 日期预览
```

用户做什么 -> 界面发生什么：

- 按住手柄并拖动 -> 时间轴放大；地图标记按连续日期范围实时预览，手柄附近临时显示前后年份。
- 松开手指 -> 一次性提交日期筛选，时间轴保持展开，地图范围不变。
- 点击时间轴空白处 -> 展开 / 收起，不改变日期范围。
- 点击完成或系统返回 -> 结束操作；不吸附到主刻度，日期仍按逐日范围计算。

时间轴主标签根据轨道宽度选择稀疏步长；次刻度只做弱提示，当前年份在手柄附近强化。详细步长算法沿用 Web 规则，但移动端不复制 Web 的尺寸。

### 5. 地区 / 筛选

地区是地图视野的摘要，不是常驻的大型筛选器：

```text
默认顶部：  中国 · 山西 · 太原  v

点击后：
+-----------------------------------+
|              MAP 背景             |
|                                   |
|-----------------------------------|
| 当前范围                           |
| 太原                               |
|                                   |
| 最近                               |
| 上海        杭州        宁波       |
|                                   |
| 所有地区                           |
| 中国                         >     |
| 日本                         >     |
|                                   |
|              下滑关闭              |
+-----------------------------------+
```

地区 Bottom Sheet 负责精确跳转；用户选择后 Sheet 收回，地图平滑移动，视野停稳后再由地图写入唯一 `currentRegion`。它不写时间或主题筛选，也不改变当前记忆列表的开合状态。

筛选入口打开同一种轻量任务层，提供主题和当前范围等短选项。日期不在这里重复出现，始终由时间轴控制。筛选过程中地图继续存在，只显示匹配标记；无结果时保留地图并显示空态动作。

### 6. 添加记忆

新增流程不是桌面端横向表单，而是地图上下文中的渐进式编辑：

```text
地图 + [添加]
    |
    +--> [拍照] [从图库选择] [手动添加]
              |
              v
        [已读取拍摄信息]
        时间 / GPS / 图片信息
        [确认]        [修改]
              |
              v
        +---------------------+
        | PHOTO               |
        | [地点] 太原   修改   |
        | [时间] 2024.05.12    |
        | 写下这段记忆……       |
        |                     |
        |              [保存]  |
        +---------------------+
```

用户做什么 -> 界面发生什么：

- 点击添加 -> 先出现来源选择任务层；选择后回到地图上下文中的编辑层。
- 选择照片 -> 自动读取 EXIF 拍摄日期、GPS 和图片信息；已有手工修改不被异步结果覆盖。
- 地点识别成功 -> 只展示确认后的城市 / 行政区摘要；点击修改可搜索候选或进入地图选点。
- 地点识别失败 -> 保留照片和可编辑文本，明确提示需要确认地点；允许只保存大致坐标或无坐标记忆。
- 日期识别失败 -> 回退文件日期并标注为可修改；不能阻塞快速保存。
- 内容输入 -> 标题和昔 / 今正文按渐进式出现；系统能推断的字段不要求重复填写。
- 点击保存 -> 本地先加密并持久化，再静默排队同步；新标记从其坐标出现，提供“继续添加 / 查看记忆”两个动作。

地点地图选点是地图的临时操作模式，不是普通 Bottom Sheet：编辑控件暂时收起，地图可缩放拖动，底部只有“确认此地点”，取消不覆盖原地点。

## 空状态与异常状态

空状态不是第七个页面，而是上述状态的内容变体：

- 首次打开且没有记忆：地图保持可用，中央只给一个轻引导“创建第一段记忆”。
- 当前时间 / 地区没有匹配：地图保留原视野，时间轴或筛选层显示 0 条结果，并给出清除对应条件的动作。
- 地图服务暂不可用：保留已缓存的记忆标记和列表阅读能力；新增地点允许手动文字或保存大致坐标。
- 照片原图读取中 / 不可用：阅读层先展示预览、状态和重试，不阻塞正文阅读。
- 同步离线 / 待重试：只显示低干扰状态，不把 API、COS 或手动上传下载暴露给正式用户。

## Bottom Sheet 规则

### 可以使用

- 地区选择与精确跳转
- 主题 / 当前范围筛选
- 日期选择（仅新增或编辑时的精确修改；浏览日期仍用时间轴）
- 照片来源与候选照片
- 短任务确认和快速操作

### 不使用

- 完整记忆阅读
- 长文字编辑
- 地图主场景本身
- 需要持续观察地图变化的地点选点

每个 Sheet 只有一个目的、一个主动作和一个明确关闭方式；不在 Sheet 里再打开 Sheet。系统返回键先关闭 Sheet，再退出当前地图层。

## 动效意图

先交互后参数。Figma 只需标注意图，具体时长、Spring 和模糊值由代码验收时调整：

| 触发 | 意图 |
| --- | --- |
| 点击照片 | 地图不切页；相机轻微调整；其他标记降低存在感；目标照片从坐标自然放大；摘要随后出现 |
| 上滑记忆卡 | 地图上下文连续保留；卡片扩大；正文按阅读顺序进入，不突然覆盖 |
| 拖动时间轴 | 时间轴从薄变厚；日期预览与标记实时变化；松开才提交筛选 |
| 选择地区 | Sheet 先收回；地图平滑移动；视野稳定后更新地区摘要 |
| 保存记忆 | 新标记从坐标出现；成功反馈与时间轴保持安全间距；不跳到新的一级页面 |
| 取消 / 返回 | 按进入顺序逆向收回；地图相机、筛选和草稿边界清晰可预测 |

地图滤镜、水晶材质和照片解密的最终效果由代码实现，Figma 不需要复制真实地图截图或精确模拟运行时滤镜。

## 系统边界与 Canonical 尺寸

### 首轮固定值

| 项目 | 规则 |
| --- | --- |
| 主设计尺寸 | iPhone 393 x 852 pt |
| 小屏验证 | 至少覆盖 320 x 568 pt；检查长标题、长地点、空态和键盘 |
| Android 验证 | 以 360 dp 宽设备检查状态栏、导航栏和底部安全区，不另画一套视觉 |
| 横屏 | v1 不承诺横屏；横屏进入时保持可读并提示回到竖屏 |
| 安全区 | 状态栏、刘海、Home Indicator / Android 手势区不放置可点击内容 |
| 键盘 | 内容编辑时键盘上方保持保存动作可达；地图不被键盘重排成新页面 |
| 大字体 | 支持系统大字体至 200%；文字可换行或滚动，不能遮挡按钮和地图层 |
| 最小命中区 | iOS 44 pt、Android 48 dp；时间轴手柄的视觉尺寸可小于命中区 |
| 地图操作区 | 未被卡片和任务层覆盖的地图均可平移 / 缩放；浮层不遮挡必要的回退和确认动作 |

### Figma 交付顺序

Figma 第一轮只需建立以下黑白帧和连线：

1. 地图默认态
2. 点击记忆后的选中态
3. 上滑后的阅读态
4. 时间轴静止与拖动中（同一状态的两种子态）
5. 地区 Sheet 与筛选 Sheet
6. 添加记忆：来源、元数据确认、渐进式编辑、保存反馈

每个帧旁边写明“用户动作 -> 状态变化 -> 地图是否仍可见 -> 返回路径”。不要把这些帧命名为“首页 / 相册 / 详情页”，也不要在此阶段添加底部四栏导航。

## 验收条件

- 从任意记忆状态都能看见一部分原地图，并能沿明确路径回到原相机视野。
- 点击记忆不触发路由级页面切换；阅读层和地图是连续状态。
- 时间轴静止时不挤压地图，拖动时手柄和年份可操作，松开才提交日期范围。
- 地区 / 筛选只在需要时出现，且一次只有一个 Bottom Sheet；日期不重复实现第二套浏览筛选。
- 添加记忆优先使用系统推断的日期和地点，识别失败时仍能保存，不要求用户重复输入。
- 393 x 852 与小屏验证尺寸下，安全区、键盘、长文字和最小点击目标都不发生遮挡或溢出。
- Figma 交付的是状态系统和转场意图，不是六张互不相干的单页。

## 明确暂不做

- 底部“首页 / 足迹 / 相册 / 我的”导航
- 独立相册首页或传统详情路由
- 把 Web 水晶时间轴按比例缩小到手机
- 用一个巨大的地区控件长期占据地图顶部
- 用 Bottom Sheet 承载长文阅读和完整编辑
- 在 Figma 中复刻真实地图瓦片、滤镜或加密照片加载细节
