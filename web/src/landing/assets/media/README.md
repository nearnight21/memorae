本目录用于存放真实的真机操作录屏（MP4/WebM）与高保真截屏（WebP/PNG）。
代码组件已内置检测：如果放入了以下命名的真实文件，页面会自动由“线框骨架占位”无缝升级为“真实产品演示”。
